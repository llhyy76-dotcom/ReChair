ReChair OMS v0.8.1.1 저장 버튼 핫픽스
========================================

이번 수정에는 Supabase SQL 작업이 없습니다.

1. 압축파일을 풉니다.

2. 압축 안의 app, components 폴더를 기존 C:\ReChair에
   폴더 구조 그대로 덮어씁니다.
   - C:\ReChair 폴더 자체를 삭제하지 마세요.
   - C:\ReChair\.git 폴더를 삭제하지 마세요.

3. GitHub Desktop Summary 입력

   Fix rental save buttons and visible feedback v0.8.1.1

4. Commit to main → Push origin

5. Vercel 배포가 Ready가 된 후 /admin/rental에서 확인합니다.

확인 방법
----------------------------------------
1. 렌탈 상담을 선택합니다.
2. 월 렌탈료를 테스트용으로 변경합니다.
3. 렌탈 정보 저장을 누릅니다.
4. 버튼이 "저장 중…"으로 바뀌는지 확인합니다.
5. 화면 하단에 "저장 완료 · 시각"이 표시되는지 확인합니다.
6. 새로고침 후 변경한 금액이 유지되는지 확인합니다.
7. 관리자 메모를 변경하고 "변경사항 저장"도 같은 방식으로 확인합니다.

오류가 발생하면 화면 하단에 실제 서버 오류가 표시됩니다.
그 오류 화면을 보내주시면 DB 컬럼 또는 환경변수 문제를 바로 구분할 수 있습니다.
