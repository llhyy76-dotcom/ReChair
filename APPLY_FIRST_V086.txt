ReChair OMS v0.8.6 적용 순서
========================================

이번 버전은 렌탈 계약자를 개인 / 개인사업자 / 법인사업자로 구분하고,
ReChair 공급자 기본정보를 한 번 저장해 새 계약서에 자동 적용합니다.

1. Supabase SQL Editor에서 아래 파일 전체를 먼저 실행합니다.

   supabase/v086_rental_contract_party_types.sql

   실행 결과가 Success인지 확인합니다.

2. 패치 ZIP의 app, components, lib 폴더와 해당 파일을
   기존 C:\ReChair의 같은 경로에 덮어씁니다.

   C:\ReChair 폴더 전체와 .git 폴더는 삭제하지 마세요.

3. GitHub Desktop Summary

   Add individual and business rental contracts v0.8.6

4. Commit to main → Push origin

5. Vercel 배포가 Ready가 된 후 /admin/rental에서 확인합니다.

최초 설정
----------------------------------------

- 렌탈 상담을 선택합니다.
- 전자 렌탈 계약서의 '렌탈 공급자 기본정보'를 엽니다.
- ReChair 운영사업자가 개인사업자인지 법인사업자인지 선택합니다.
- 사업자등록증과 동일하게 입력한 뒤 '공급자 기본정보 저장'을 누릅니다.
- 작성 중인 초안이 있다면 저장과 동시에 현재 초안에도 적용됩니다.

기존 계약 처리
----------------------------------------

- 기존 서명 완료 계약서는 수정하지 않고 그대로 보존됩니다.
- 기존 작성 중 초안은 계약자 유형을 선택하고 저장하면 v2 형식으로 전환됩니다.
- 이미 고객 서명 대기 중인 계약의 내용을 바꿔야 한다면 발송 취소 후 새 계약서를 작성합니다.
- 개인용/영업용(코인형)은 렌탈 유형이며, 개인/개인사업자/법인은 계약자 유형입니다.

개인정보 주의
----------------------------------------

- 주민등록번호와 신분증 사진은 입력하거나 첨부하지 않습니다.
- 계약 이행에 필요한 최소 정보만 입력합니다.
- 실제 영업 전 최종 계약 조항은 국내 소비자법·계약법 전문가의 검토를 권장합니다.
