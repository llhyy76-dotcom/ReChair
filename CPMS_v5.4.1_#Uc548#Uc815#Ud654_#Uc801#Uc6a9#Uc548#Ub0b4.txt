CPMS v5.4.1 Stable

수정 내용
1. Archive 이동 안정화
- Master 저장 검증을 통과한 파일만 Archive로 이동
- 파일별 3회 재시도
- 드라이브 간 이동 실패 시 복사→크기검증→원본삭제 방식으로 재시도
- 일부 파일 이동 실패가 전체 업데이트를 중단하지 않음
- 실패 파일은 Update 폴더에 그대로 유지
- 처리 로그와 rejected_manifest에 실패 사유 기록
- Archive 성공/실패 건수를 진행화면에 표시

2. History Explorer 응답없음 개선
- History Excel 읽기를 메인 UI가 아닌 별도 스레드에서 실행
- 창을 먼저 표시하고 백그라운드에서 로딩
- 표 화면은 최대 2,000행만 렌더링하여 대용량 History에서도 멈춤 방지
- 전체 검색과 집계는 모든 History 데이터를 기준으로 수행
- 조회 건수가 2,000건을 넘으면 화면표시 건수를 별도 안내

3. Update 대기 표시 개선
- 처리대상 수량과 Update 폴더 전체 파일 수량을 함께 표시
- 제조사 미분류 Excel 및 PDF 검토 건수를 별도 표시

적용
- 기존 CPMS 폴더를 백업합니다.
- 이 개발본의 파일을 기존 CPMS 폴더에 덮어씁니다.
- 기존 dist 폴더를 삭제합니다.
- CPMS_실행.bat를 실행해 CPMS.exe를 다시 빌드합니다.

확인 권장
- Excel에서 Update 파일이나 Master.xlsx가 열려 있지 않은 상태로 실행
- 완료 후 Update 폴더와 Archive/제조사/날짜 폴더 확인
- History 조회 버튼을 누른 뒤 '불러오는 중' 문구와 정상 화면 전환 확인
