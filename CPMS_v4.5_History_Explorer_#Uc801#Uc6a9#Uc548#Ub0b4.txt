CPMS v4.5 History Explorer 적용 안내

주요 기능
- 메인 화면의 기존 검색 버튼이 'History 조회'로 변경됩니다.
- 요청번호, 모델, 부품번호, 한글/영문 부품명, 원본파일, 날짜 통합검색
- 제조사 및 가격이력/변경이력 필터
- 이전값, 최근값, 변동액, 변동률, 요청번호와 원본파일 표시
- 가격 상승 행은 연한 붉은색, 하락 행은 연한 푸른색으로 구분
- 최신 History Excel 파일 바로 열기
- 내부 이벤트 ID는 화면에서 숨김

적용
1. 기존 CPMS 폴더를 복사해 보관합니다.
2. ZIP 내용을 현재 CPMS 프로젝트 루트에 덮어씁니다.
3. 프로그램을 실행하고 하단 'History 조회' 버튼을 누릅니다.
4. 기존 History_2026.xlsx를 그대로 사용합니다.

정상 확인
- AC2502, L500, Cable, 케이블, 날짜 등으로 검색됩니다.
- 조회 건수 = 가격이력 + 실제 변경이력으로 표시됩니다.
