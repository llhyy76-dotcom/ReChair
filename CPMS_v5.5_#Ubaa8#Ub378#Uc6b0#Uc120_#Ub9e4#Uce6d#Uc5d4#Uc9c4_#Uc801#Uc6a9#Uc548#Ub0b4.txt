CPMS v5.5 Model-First Matching

개선 목적
- Pad, Back, XL400 / 패드, 등, XL400처럼 모델과 부품이 명확한데도
  punctuation, 공백, 한영 표기 차이 때문에 단가가 매칭되지 않는 문제 개선
- 동일한 일반 부품명이 다른 모델이나 제조사로 잘못 연결되는 문제 차단

매칭 순서
1. 제조사: 발주 시트 제조사 Master만 검색
2. 적용모델: XL400이면 XL400 후보만 유지
3. 부품코드: 일치 시 최우선
4. 영문명과 한글명 정규화 비교
5. 토큰 기반 유사도와 문자열 유사도
6. 후보가 비슷하게 경합하면 자동 확정하지 않고 매칭 확인 표시

정규화 예시
- Pad, Back, XL400
- Pad Back XL400
- PAD / BACK / XL400
위 세 표현을 같은 토큰으로 비교합니다.

한영 공통 토큰 예시
- Pad / 패드
- Back / 등 / 등받이
- Cable / 케이블
- Remote / Remocon / 리모컨
- Motor / 모터
- Cover / 커버

안전장치
- 제조사 간 교차 검색 금지
- XL400과 XL500/X5000 등 다른 모델은 이름이 같아도 후보에서 제외
- 모델이 없는 발주 품목은 신뢰도 상한 79점
- 후보 점수가 비슷하고 부품명이 다르면 자동 매칭 대신 후보경합 표시
- 자동 매칭 기준 82점 이상

적용
1. 기존 CPMS 폴더 백업
2. 압축 내용을 기존 폴더에 덮어쓰기
3. 기존 dist 폴더 삭제
4. CPMS_실행.bat 실행
5. 동일 발주파일을 다시 '발주 분석'
6. 결과의 매칭방식, 매칭신뢰도, Master 최신단가 확인
