CPMS v4.3 History Engine
========================

주요 기능
1. 제조사별 Master 업데이트 전/후를 자동 비교합니다.
2. 신규, 삭제, 단가/수량/금액, 적용모델, 부품명, SPEC, 기준년도 변경을 기록합니다.
3. History/History_연도.xlsx 파일에 변경이력을 누적합니다.
4. 이벤트ID를 이용해 같은 변경이력의 중복 기록을 방지합니다.
5. History 저장 또는 후속 처리 중 오류가 발생하면 해당 제조사의 Master를 백업본으로 자동 복구합니다.
6. 업데이트 결과 보고서와 GUI 로그에 History 기록 건수와 파일 경로를 표시합니다.

적용 방법
- 이 ZIP의 파일을 기존 CPMS 프로젝트 폴더에 덮어씁니다.
- 기존 Manufacturers, Archive, Backup, Log 데이터는 삭제하지 않습니다.
- requirements.txt의 openpyxl이 설치되어 있어야 합니다.

실행 후 확인
- Update 폴더에 신규 요청 파일을 넣고 업데이트를 실행합니다.
- History/History_2026.xlsx 생성 여부를 확인합니다.
- 변경이력 시트에서 제조사, 요청번호, 원본파일, 변경 전후 값을 확인합니다.

주의
- Archive 전체 재생성 모드는 현재 History 기록 대상에서 제외했습니다. 전체 재생성은 기준 데이터 재구축 작업이므로 일상 업데이트 이력과 분리했습니다.
- 최초 v4.3 업데이트에서는 기존 Master 전체를 이력으로 소급 기록하지 않고, 이번 실행에서 실제 발생한 변경만 기록합니다.
