ReChair OMS v0.7.7 적용 순서
========================================

이 패치는 v0.7.6 모바일 렌탈 화면 개선본이 적용된 소스를 기준으로 합니다.
Supabase SQL 실행은 필요하지 않습니다.

1. 압축을 풉니다.

2. 아래 파일을 C:\ReChair의 같은 위치에 덮어씁니다.

   app/rental/rental.css

3. GitHub Desktop Summary에 아래 문구를 입력합니다.

   Fix mobile rental price hidden by product image v0.7.7

4. Commit to main → Push origin

5. Vercel 배포 상태가 Ready가 된 후 휴대전화에서 /rental을 새로고침합니다.

반영 내용
----------------------------------------
- 모바일 상품 이미지를 170px 영역 안에서만 표시
- 이미지가 카드 본문을 덮지 않도록 경계와 레이어 분리
- 브랜드·상품명·월 렌탈료가 이미지 아래에서 순서대로 표시
- 가격 줄의 최소 높이와 줄간격 확보
- 기존 상품 이미지 크기, 렌탈 카드 간격, 상담 기능 유지
