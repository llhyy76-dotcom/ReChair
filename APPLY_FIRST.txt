ReChair OMS v0.7.3 모바일 첫 화면 최적화 패치

적용 전제
- ReChair OMS v0.7.2가 먼저 적용된 프로젝트용입니다.
- Supabase SQL 실행이나 환경변수 변경은 필요하지 않습니다.

적용 방법
1. 이 압축파일을 풉니다.
2. 압축을 푼 폴더 안의 components 폴더를 C:\ReChair에 붙여넣습니다.
3. 같은 이름의 파일 2개를 모두 덮어씁니다.
   - components/HeroV072.module.css
   - components/HeaderV072.module.css
4. C:\ReChair 폴더와 .git 폴더는 삭제하지 마세요.
5. GitHub Desktop에서 변경 파일 2개를 확인합니다.
6. Summary에 아래 내용을 입력합니다.

Optimize mobile first view and hero typography v0.7.3

7. Commit to main을 누른 뒤 Push origin을 누릅니다.
8. Vercel 배포가 Ready가 되면 휴대전화에서 새로고침하여 확인합니다.

확인 사항
- 제목이 기존보다 작게 표시되는지
- 6개 서비스 카드가 3열 x 2행으로 유지되는지
- 큰 렌탈 상자가 보이는지
- 무료 견적 신청과 판매상품 보기가 가로 한 줄로 표시되는지
- 첫 화면에서 최소한 무료 견적 신청 버튼까지 보이는지
