ReChair OMS v0.8.1 적용 순서
========================================

이번 버전은 렌탈 설치일정과 현장기사 업무를 연결합니다.
반드시 SQL을 먼저 실행한 뒤 소스파일을 업로드하세요.

1. Supabase SQL Editor 열기

2. 아래 파일의 전체 내용을 붙여넣고 Run 실행
   supabase/v081_rental_installation_operations.sql

3. 화면 하단에 Error 없이 Success가 표시되는지 확인

4. 이 압축파일의 폴더 구조를 그대로 유지한 채
   C:\ReChair 폴더에 덮어쓰기
   - C:\ReChair 폴더 자체를 삭제하지 마세요.
   - C:\ReChair\.git 폴더를 삭제하지 마세요.

5. GitHub Desktop Summary 입력
   Connect rental installation calendar and technician workflow v0.8.1

6. Commit to main → Push origin

7. Vercel 배포가 Ready가 된 뒤 테스트

확인 위치
----------------------------------------
- 렌탈 9단계: /admin/rental → 고객 상담 선택
- 설치일정: 렌탈 상세의 "설치 일정·기사 연동"
- 전체 일정: /admin/schedule (현장 캘린더)
- 기사 화면: /technician

중요한 상태 전환
----------------------------------------
계약완료
→ 설치 일정 생성
→ 설치예약
→ 기사 현장보고 최종 제출
→ 검토대기
→ 관리자 승인
→ 운영중 자동 전환

관리자가 반려하면 렌탈 상태는 설치예약으로 유지되며,
기사 화면에서 반려 사유를 확인하고 작업보고를 보완할 수 있습니다.
