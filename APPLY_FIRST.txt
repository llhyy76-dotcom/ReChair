ReChair OMS v0.7.8 적용 순서
========================================

이 패치는 v0.7.7까지 적용된 최신 ReChair 소스를 기준으로 합니다.
Supabase SQL 실행은 필요하지 않습니다.

1. 압축을 풉니다.

2. 패치 안의 app, components 폴더를 C:\ReChair에 복사합니다.
   같은 경로의 파일만 덮어씁니다.
   C:\ReChair 폴더 자체와 .git 폴더는 삭제하지 않습니다.

3. 아래 새 파일 2개가 생성되었는지 확인합니다.

   app/consult/ConsultPageV078.module.css
   components/ConsultationCompactV078.module.css

4. GitHub Desktop Summary에 아래 문구를 입력합니다.

   Compact mobile consultation form layout v0.7.8

5. Commit to main → Push origin

6. Vercel 배포 상태가 Ready가 된 후 휴대전화에서 상담 화면을 새로고침합니다.

반영 내용
----------------------------------------
- 모바일 상담 소개 영역 높이 축소
- 선택 상품 카드를 64px 이미지의 요약 카드로 압축
- 상품 카드와 입력 폼 사이 간격 축소
- 입력 폼 외곽·내부 여백과 필드 간격 축소
- 입력칸 높이를 50px로 통일
- 주소 입력과 주소 검색 버튼을 한 줄로 배치
- 개인정보 안내를 모바일 2열 요약으로 압축
- 개인정보 동의, 렌탈 사진 제외, 기존 접수 API 유지
- PC 화면은 기존 구성 유지
