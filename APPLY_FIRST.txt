ReChair OMS v0.7.5 적용 순서
========================================

이 패치는 v0.7.4 렌탈 상품 관리 패치가 반영된 최신 ReChair 소스를 기준으로 합니다.

1. 안전 확인
----------------------------------------
- C:\ReChair 폴더와 Supabase DB를 먼저 백업합니다.
- C:\ReChair 폴더 자체와 .git 폴더는 삭제하지 않습니다.

2. Supabase SQL을 가장 먼저 실행
----------------------------------------
- Supabase Dashboard → SQL Editor → New query
- 아래 파일을 열어 전체 내용을 붙여넣고 Run을 누릅니다.

  supabase/v075_privacy_security_hardening.sql

- Success가 확인된 후에만 다음 단계로 이동합니다.

3. 소스 덮어쓰기
----------------------------------------
- 이 패치 폴더 안의 app, components, lib, supabase 폴더를 C:\ReChair에 복사합니다.
- 같은 경로의 파일만 덮어씁니다.
- app/globals.css는 이번 패치에서 수정하지 않습니다.

4. GitHub 반영
----------------------------------------
GitHub Desktop Summary:

Harden customer privacy and remove rental photo upload v0.7.5

Commit to main → Push origin

5. Vercel 배포 후 확인
----------------------------------------
- /consult?service=rental-personal : 제품 사진 업로드 영역이 없어야 합니다.
- /consult?service=rental-commercial : 제품 사진 업로드 영역이 없어야 합니다.
- 렌탈 상품에서 상담 신청 : 선택한 상품 정보가 표시되고 사진 영역은 없어야 합니다.
- 중고판매 또는 출장수리 상담 : 선택형 사진 영역은 유지되어야 합니다.
- 개인정보 동의 체크 없이 접수하면 접수가 차단되어야 합니다.
- /api/consultations 주소를 브라우저에서 열면 405가 나와야 합니다.
- 관리자 로그인 후 상담 목록과 기존 상담사진은 정상적으로 보여야 합니다.

중요
----------------------------------------
- SQL은 기존 상담을 즉시 삭제하지 않습니다. 기존 건에는 생성일 기준 1년의 보유 만료일을 표시합니다.
- 실제 만료일 자동 삭제 작업은 별도 운영 기능으로 추가해야 합니다.
- 개인정보처리방침 공개 페이지는 사업자·담당자 정보가 확정된 뒤 작성해야 합니다.
