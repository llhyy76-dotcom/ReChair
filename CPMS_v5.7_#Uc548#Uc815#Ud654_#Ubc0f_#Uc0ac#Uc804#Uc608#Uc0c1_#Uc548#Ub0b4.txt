CPMS v5.7 Stability & Simulation

1. OCR Worker 분리
- Tesseract를 별도 CPMS-OCR-Worker 프로세스에서 실행
- Tesseract 0xc0000142 또는 비정상 종료가 발생해도 GUI 본체 유지
- 실패한 페이지/PDF만 로그에 기록하고 다음 작업 계속
- Windows 오류창 억제를 OCR Worker와 OCR 상태 확인 모두에 적용
- frozen EXE용 multiprocessing.freeze_support 적용

2. 단가 미회신 요청서
- 수량·단가·합계가 공란인 요청서를 파싱 실패로 표시하지 않음
- 제조사 결과: '단가 미회신 N건 보관 - Master 반영 제외'
- 보관 위치:
  Excluded/Unpriced_Request/YYYYMMDD
- 원본 삭제 없음

3. 업데이트 예상
- 파일 진단 창에 '업데이트 예상' 버튼 추가
- A등급 파일만 대상으로 실제 Master와 비교
- 제조사별 예상 신규부품, 가격변동, 중복 표시
- Master, History, Archive는 변경하지 않는 Dry Run

4. 파일 진단
- A 자동반영
- B 분리/수정/검토
- C PDF·이미지 OCR 검토
- D 단가 Master 제외 또는 단가 미회신 보관
