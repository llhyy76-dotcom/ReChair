ReChair OMS v0.8.7 적용 순서
============================

이번 버전은 렌탈 안마의자를 상품 수량이 아니라 실물 1대 단위로 관리합니다.
SQL을 먼저 실행하지 않고 코드를 배포하면 새 관리자 화면에서 조회 오류가 발생합니다.

1. Supabase SQL Editor에서 아래 파일 전체를 실행합니다.
   supabase/v087_rental_asset_registry.sql

2. 패치 폴더의 파일을 기존 C:\ReChair에 같은 경로로 덮어씁니다.
   C:\ReChair 폴더와 .git 폴더는 삭제하지 마세요.

3. GitHub Desktop Summary
   Add serial-level rental asset registry v0.8.7

4. Commit to main → Push origin → Vercel 배포 완료(Ready) 확인

5. 배포 후 관리자에서 아래 주소를 엽니다.
   /admin/rental/assets

6. 매우 중요한 최초 전환 순서
   가. 상품별로 현재 보유한 실물 안마의자를 모두 등록합니다.
   나. 이미 설치예약·운영 중인 계약을 열어 실제 설치된 자산을 먼저 연결합니다.
   다. 등록 수량과 실제 보유 수량, 기존 계약 연결 상태가 맞는지 확인합니다.
   라. 그 다음에만 상품별 "관리 적용"을 누릅니다.

"관리 적용" 이후에는 해당 상품의 재고수량, 렌탈가능 상태, 고객 페이지 노출이
개별 자산 상태를 기준으로 자동 계산됩니다.

기존 상품은 관리 적용 전까지 종전 수량 방식으로 그대로 작동합니다.
