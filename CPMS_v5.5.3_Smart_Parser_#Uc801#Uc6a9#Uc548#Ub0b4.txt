실제 원본 검증 파일
- 2.NC부품 단가 확인 요청 2104 - 회신.xlsx

확인된 실제 원인
1. 파일명이 NC2104 형식이 아니어서 제조사 분류가 UNKNOWN이 됨
2. 요청번호가 전체 파일명으로 저장됨
3. 가격 시트 61행 외에 'NC추가 유상발주 (2)' 보조 시트 41행까지 중복 파싱됨
4. 화면상 파싱 실패처럼 보였지만 원본 표 자체와 수식 캐시값은 정상

수정 결과
- 제조사: NC
- 요청번호: NC2104
- 사용 시트: NC
- 추출 품목: 61행
- 단가 보유: 61행
- 보조 계획 시트: Master 반영 제외
- 수식 합계: Excel 저장 계산값을 사용하고 수량×단가 검증

새 로그 예시
Smart Parser: 제조사 NC / 요청번호 NC2104 /
NC:legacy_price_request, 61행

적용
1. 기존 CPMS 폴더 백업
2. 압축 내용을 기존 폴더에 덮어쓰기
3. 기존 dist 폴더 삭제
4. CPMS_실행.bat 실행
5. 원본 파일을 Update에 둔 상태에서 업데이트 시작
6. 로그에서 NC2104 / 61행 / 단가 61행 확인
7. 완료 후 Archive/NC/날짜 폴더 이동 확인
