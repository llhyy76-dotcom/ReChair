CPMS v4.3.2 History 지표 통합 패치

핵심 수정
1. 서로 의미가 다른 가격 지표를 분리했습니다.
   - 이번 실행 가격이력 검출: 투입 파일의 단가가 기존 과거 단가군과 다른 경우
   - 누적 가격변동 부품: Master 전체에서 단가가 2개 이상 존재하는 부품 그룹(Dashboard와 동일 의미)
   - History 실제변경: 업데이트 전 Master와 저장 후 Master의 필드가 실제로 달라진 건수

2. History_연도.xlsx의 실행이력 시트에 아래 열을 추가했습니다.
   - 이번실행가격이력검출
   - 누적가격변동부품

3. GUI 문구를 명확히 변경했습니다.
   기존 '가격변동' -> '이번 실행 가격이력 검출'
   완료 로그에 누적 가격변동 부품과 History 실제변경을 함께 표시합니다.

정상 판정 예시
- 같은 파일을 동일 내용으로 재처리한 경우
  이번 실행 가격이력 검출: 1
  누적 가격변동 부품: 4
  History 실제변경: 0
  위 결과는 정상입니다. 세 지표의 의미가 서로 다릅니다.

OCR 관련
- 본 패치는 History/가격 지표 통합 패치입니다.
- Tesseract 미설치 상태의 PDF OCR 문제를 설치 없이 해결하는 패치는 아닙니다.
- PDF OCR은 Tesseract 설치 및 PATH 설정 여부에 따라 동작합니다.

검증
- Python import/구문 검사 통과
- 자동 테스트 2건 통과

적용
1. 현재 CPMS 폴더 전체를 백업합니다.
2. ZIP 내용을 CPMS 프로젝트 최상위 폴더에 덮어씁니다.
3. build.bat로 exe를 다시 빌드하거나 Python 실행본으로 먼저 시험합니다.
4. 동일 파일 재처리 후 History/History_2026.xlsx의 실행이력 열을 확인합니다.
