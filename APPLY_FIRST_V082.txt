ReChair OMS v0.8.2 적용 순서
========================================

이번 버전은 렌탈 운영·납부센터를 추가합니다.
환경변수 추가는 필요하지 않지만, 새 DB 테이블을 먼저 만들어야 합니다.

1. Supabase SQL Editor를 엽니다.
2. 아래 파일의 전체 내용을 붙여넣고 Run을 누릅니다.
   supabase/v082_rental_billing_operations.sql
3. 결과가 "Success. No rows returned"이면 정상입니다.
4. 패치 폴더 안의 파일을 C:\ReChair의 같은 경로에 덮어씁니다.
   C:\ReChair 폴더 자체와 .git 폴더는 삭제하지 마세요.
5. GitHub Desktop에서 다음 Summary를 입력합니다.

   Add rental billing and contract operations center v0.8.2

6. Commit to main → Push origin 순서로 반영합니다.
7. Vercel 배포 상태가 Ready가 된 뒤 아래 주소로 접속합니다.
   https://re-chair.vercel.app/admin/rental/operations

확인 위치
----------------------------------------
- 관리자 → 렌탈관리 → 상단의 "운영·납부센터"
- 렌탈 고객 선택 → 렌탈 정보 영역 아래의 "운영·납부 보기"

처음 사용할 때
----------------------------------------
1. 렌탈관리에서 계약 시작일, 계약기간, 월 렌탈료, 매월 결제일을 저장합니다.
2. 운영·납부센터에서 해당 고객을 선택합니다.
3. "계약기간 청구일정 생성"을 누릅니다.
4. 입금된 월의 "납부 처리" → "납부완료 저장"을 누릅니다.

주의
----------------------------------------
- 이 기능은 관리자용 납부 장부입니다. 카드·자동이체 결제대행과 은행 입금
  자동확인은 아직 연결되지 않았습니다.
- 납부기한이 지났지만 상태가 "납부예정"인 월은 자동으로 "미납" 표시됩니다.
- 계약 종료일이 60일 이내이면 "종료 임박", 이미 지났으면 "종료 경과"로 집계됩니다.
- 청구일정을 다시 계산해도 이미 납부완료 또는 면제 처리된 기록은 유지됩니다.
